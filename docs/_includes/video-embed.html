{% comment %} Usage: {% include video-embed.html url="VIDEO_ID" caption="Caption text" %} VIDEO_ID should be just the YouTube video ID (e.g., "Iov8SzQ97aU"). Pass title="..." instead of caption="..." where the surrounding prose already introduces the video: it names the video for assistive technology without printing a caption underneath. Renders a poster image rather than the player. The iframe is swapped in on click by the handler in custom-head.html, so no request reaches YouTube until the visitor asks for the video. Posters live in /media/video-posters/ and are produced by tools/fetch-video-posters.sh. {% endcomment %} {%- assign video_title = include.title | default: include.caption | default: 'YouTube video' -%}
