<p>
  dmenu-extended brings files, folders and applications into one searchable menu. Type part of a name, choose a result and open it without reaching for the mouse.
</p>
<p>
  I wrote it in Python as an extension to <a href="https://tools.suckless.org/dmenu/">dmenu</a>. It also supports rofi as the menu interface, with plugins, command aliases and filters for customising what appears. I started the project in 2013; the repository includes automated tests and continuous integration.
</p>
